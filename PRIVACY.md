# Public participation and privacy

This repository is public. Files, GitHub identities, acknowledgments, decisions and history may be cloned. Do not submit credentials, private conversations, sensitive personal data or unconsented biographies. Removing a file or website projection cannot erase all public clones.

Credit uses stable numeric GitHub IDs and mutable display handles. Legal name, employer, location, demographics and portrait are optional. Profiles/stories use explicit consent; ranking/story opt-out suppresses presentation while preserving appropriate audit provenance. Missing/disputed allocations remain held, never transferred by default.

Website sessions, OAuth tokens, quota telemetry and private incident evidence are stored separately and never committed here. A monitored restricted reporting route and concrete retention choices are launch gates until verified. No proposed mailbox is advertised as staffed.

Urgent suppression must cover pages, APIs, downloads, exports, caches and rebuilds; a stale view cannot keep serving suppressed content. Preserve minimized audit metadata. Any public Git-history rewrite is separately authorized. Private account/privacy requests use the verified restricted route and do not replace PR research intake.
