# Rights map

Project-authored software in `src/`, `scripts/`, `tools/`, tests and authored software configuration uses **Apache-2.0**. Original project documentation, policy, research prose and public grading prompts use **CC BY 4.0**. Original data needs an explicit per-manifest license; do not infer it from the root.

Third-party scans, papers, transcriptions, corpora and quotations retain their rights. Source/asset manifests record provenance, access, redistribution, attribution, actual retrieval and derived lineage. A URL is not permission. Repository licenses never relicense third-party material. Contributors certify authority and preserve notices. Contested rights remain a hold, not an automated legal conclusion.
