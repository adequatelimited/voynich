# Credit and grading threat model

| Attack | Observable evidence and control | Response and appeal |
|---|---|---|
| PR/file/proposal fragmentation | Same acceptance test and useful scope across PRs; cumulative canonical family high-water | Consolidate automatically with public reasons; scope appeal on evidence |
| Family alias, seed laundering, renamed releases | Alias/successor records, occupied seed baseline, immutable history | No reset of consumed credit; unresolved baseline held |
| Manufactured defect and repair | Compare net capability to last valid state and original obligations | No fresh repair points; factual conduct review where evidenced |
| False results/independence | Missing commands/outputs/trusted receipts, overlapping collaborators, contradictory provenance | Evidence hold/lower justified tier; no fabricated expert personas |
| Grade lottery through reruns | Exact action and merit digests, first-success cache, stable family history, bounded quotas | Reuse equivalent judgments; regrade only with material evidence/authorized correction |
| Prompt injection or modified grader | Incoming instructions are evidence; protected policy and tokenless tool-less model | Reject authority request, protect secrets, process legitimate policy changes separately |
| Forged receipts/IDs/acknowledgments | Authenticated App/signature/delegation and actual GitHub commenters | No allocation without verification; withheld shares and independent factual appeal |
| Credit theft or correction windfall | Exact 10,000-bps map, consent receipts, append-only corrections | Hold disputed shares; no default transfer/refill/new earning date |
| Queue/merge timing and Sybil spam | Stable trusted merge order, authenticated account limits, global budget and fair queue | Visible resource holds; identity patterns alone never prove guilt |
| Hidden payload or off-topic upload | Complete bounded inventory/inspection and rights/relevance gates | Unsupported means uninspected; restricted incidents do not echo private content |
| Cherry-picking and restricted data | Declared search scope, all material variants and explicit exclusions | Limit credit to inspectable evidence; never claim omniscience about private experiments |
| Appeal/moderation/funding farming | No competitive credit for routine service/support; distinct artifact only | Service acknowledgment separately; factual appeals never require points |

Tests in `tests/` cover deterministic arithmetic, trust, reuse and content boundaries. Synthetic calibration cases cover qualitative over/undercredit examples but have not passed the actual AI reference/evaluation trials. Hidden collaboration, private experimentation, subjective value, resource advantages and strategic timing remain partially observable. No list is exhaustive. Publish emerging interpretations prospectively, retain appeals and never infer motives from a high claim or unfamiliar hypothesis.
