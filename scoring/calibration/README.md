# Calibration status

The boundary fixtures are **synthetic unreviewed draft cases**, not calibrated truth, production judgments or manuscript findings. At least two qualified reference calibrators must inspect/reconcile labels, and the configured real profile must run all cases. Record actual evidence, people, all trials and usage; do not invent approvals or successful model performance.

Launch requires every contribution route's eligible/ineligible or service-only boundary, every ledger invariant and every high-risk allowed/prohibited case. Targets: 100% deterministic/critical boundaries; ≥80% exact tier and ≥95% adjacent tier against reconciled human references. Separately run ≥3 matched independent local/official pairs per case with ≥90% exact decomposition/tier/increment agreement, ≥95% adjacent tier and 100% arithmetic agreement given identical judgments. Retain all runs and route failures, uncertainty widths, false flags and usage distributions. A broad 0–20 forecast is not a pass.

No actual-model trial, reconciled human labels or cost/latency calibration has occurred as part of the unit-test run. Reference labeling and bounded inference allowance remain external gates. These fixtures and tests are a starting evaluation corpus, not permission to activate public ranked intake.
