# Publication release requirements

- Verify original claims, code/input/output hashes, figures, uncertainty and replication evidence.
- Verify third-party rights, citations and individual data licenses.
- Record actual consented contribution roles, conflicts, AI disclosure and target-venue authorship rules.
- Obtain the actual authors' manuscript approval and accountability agreement.
- Preserve negative findings, competing explanations and reproducibility limitations.
- Issue an immutable research release and citation metadata only after those checks occur.

No points threshold guarantees an author position or a solved manuscript.
