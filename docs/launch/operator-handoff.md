Maintain separate authority for research merge actions, prospective governance changes, website deployment and private-runner workflow dispatch. The public GitHub App must never receive write access to the private operational code. Public PRs carry research, contribution metadata, AI disclosure, claimed credit and attribution. The contributor's own branch is the correction workspace.

Before ranked activation, pin the public release, assess existing seed families, publish the effective model/profile/prompts and authority, and record the launch gates listed in [status.md](status.md). Configure a finite, expiring resource allocation; confirm subscription identity, no paid-extra/API fallback, output/runtime ceilings, fresh observations and a personal-use reserve. The optional private GitHub Actions assessor runs one stage per ephemeral job. Cloudflare authorizes the work first. GitHub job reruns cannot reset model or dispatch usage. Private Actions minutes have their own budget. Scientific code execution uses a separate secret-free environment; it must not inherit the subscription, GitHub broker or Cloudflare deployment credentials.

Every accepted research merge must have exact-byte provenance. Every score decision must have a verified AI assessment, deterministic ledger check and actual GitHub merge timestamps. Missing attribution acknowledgment holds only that share. Corrections preserve earning dates and family occupancy. A leaderboard is a credit record, not proof of decipherment or guaranteed authorship.

For incidents: pause new dispatch; preserve restricted evidence and action intents; suppress affected public content; revoke compromised credentials/sessions; reconcile GitHub, ledger and resource history before resuming. Never restore an empty budget as a recovery shortcut. Rotate signing keys through public, dated authority records before changing the active verifier. Appeals resolve facts or prospective rules and trigger an AI re-evaluation where merit changes; humans do not edit point totals.

Private operational guides contain deployment commands and secret names. Secret values, subscription telemetry and private investigation details must not be copied into this public repository.
