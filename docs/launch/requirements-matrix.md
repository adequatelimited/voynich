# Implementation and launch requirements

| Requirement | Implementation or evidence | Activation dependency |
| --- | --- | --- |
| Mission and scope | README, research charter, RULES R1–R8 | No linguistic content or translation success assumed |
| Fork/branch/PR contribution workflow | CONTRIBUTING, templates, manifests, public CI, website guide | Real fork pilot |
| Artifact and unique-direction credit | SCORING, GRADING, artifact/direction schemas, worked examples | Actual inspection and calibrated model |
| Predictable qualitative grading | Published prompts, profiles, rubric, preview CLI, boundary fixtures | Actual-model calibration; fixtures alone are insufficient |
| Anti-gaming and fair marginal credit | Canonical families, aliases, seed occupancy, cumulative tiers, conserved shares | Official seed assessment and novel-scope factual evidence |
| All official merit judgments AI | Two blind assessments; one bounded adjudication; versioned receipts | Authorized subscription runtime |
| Durable resource safeguards | Private account-wide controller, reservations, lease fencing, replay tombstones | Operator allocation and fresh provider observations |
| PR feedback and correction loop | Current summary, machine-readable report, receipt-bound acknowledgment | Installed GitHub App and live pilot |
| Merge and score authority separation | Restricted GitHub broker, exact artifacts, independent deterministic decision check | Protected branch and prospective delegation |
| Score corrections and held shares | Append-only public ledger and conserved release/correction operations | Verified facts; no manual point edits |
| Leaderboards and attribution | All-time, UTC weekly/monthly, categories, newcomer and consent-aware views | Verified settled decisions; no seeded/fake ranks |
| Website and GitHub login | Private Cloudflare Worker/React website, D1 OAuth/session state | Deployed credentials and real login check |
| Automatic website refresh | Signed attendant projections, atomic D1 pointer, service binding | Verified publication; suppression applied on every read |
| Scientific seed and collateral | Sources, transcriptions, methods, claims, branches, directions and tasks | Remaining historical/image/source-access gaps |
| Reproducible research loop | CPU prepare/run/compare/bundle harness, three actual baseline variants | Independent scientific reproduction |
| Content, rights and safe artifacts | Rules, license/provenance records, protected paths, inspection holds | Verified binary/visual/execution adapters as applicable |
| Security and recovery | Role-separated endpoints, signed webhooks, inbox reconciliation, action intents | Real end-to-end incident/recovery pilot |
| Governance and publication | GOVERNANCE, AUTHORSHIP, AI_POLICY, PRIVACY, SECURITY, solution protocol | Maintainer roster and independent expert participation |
| Reuse as a qualitative research harness | Public package/adapter contracts separated from private operational authority | General packaging remains a separate product decision |

The signed live deployment inventory supplements this matrix. A implemented code path is not evidence that its real-world dependency or scientific acceptance gate has passed.
