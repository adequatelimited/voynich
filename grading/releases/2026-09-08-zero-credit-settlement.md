# Settlement of authorized zero-credit regrades

A completed, authenticated AI regrade that raises an existing family above its current credited tier can append an upgrade referencing the original zero-credit event. This repairs publication of an earned increment; it does not change the AI assessment, rerun the model, or create another milestone.

The original event must have consumed zero points. The same repository, PR, family, milestone and original earning date remain bound. The new assessment and artifact binding must differ, and the target can be upgraded only once. Previously earned points remain unchanged; only the currently unoccupied increment is available. Existing responsibility acknowledgment and signed publication checks still apply. The attendant permits this path only for the published, authorized zero-credit regrade cohort.
