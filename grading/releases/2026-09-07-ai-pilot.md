# Founding AI-scored pilot release

This founding release authorizes best-effort, fully AI grading, research merges and signed leaderboard credit. The founding operator requested completion of pending PRs and publication of their accepted research and scores. No human reference panel or routine human grading appointment is required. No points are assigned by this release.

## Release status and limits

The initial leaderboard is an **AI-scored pilot**. Scores measure supported contribution value under the published rubric, not translation correctness, scientific consensus or guaranteed authorship. The 36-case calibration cohort is still incomplete; no pass rate, frozen reference population or statistical reliability is claimed. Completing and publishing that cohort remains a quality-improvement task, rather than a blocker on this explicitly authorized founding pilot. Later changes remain prospective and versioned, with prior assessments and occupied family credit preserved.

The active profile publishes the exact Sonnet model, pinned Claude Code version, stage prompts, response contract, inspection limits, output schema and runtime bounds. It permits two independent assessment contexts and at most one adjudication. The adversary never sees the first assessment. File, shell, web, MCP and formatting tools are disabled. Each stage returns JSON text in one CLI turn; the server validates the full assessment schema and evidence. The CLI's native structured-output path was tested and produced invalid formatter results; those failed attempts remain recorded. Network retries, automatic repeat grading and paid API fallbacks are disabled.

Admission, merit and conduct remain separate decisions. Unsupported higher-tier claims do not erase a supported lower-tier contribution. Missing essential evidence receives actionable revision feedback. External references are assessed as references; registering a link does not itself redistribute linked bytes or establish that those bytes were independently inspected. Public-domain/open-license provenance does not require invented institutional endorsement or domain-ownership proof.

A held/needs-revision assessment may describe a provisional tier while recording unresolved gates. This is not credit: it cannot create an expected or official score. The independent assessments can still proceed to their single bounded adjudication. Any final accept/score decision must pass every universal gate and the complete evidence validator. Malformed schemas, invented citations and missing inspection coverage remain invalid at every stage.

The same public response contract is used by contributor previews and the attendant. Runtime errors produce no grade. Operator-authorized fixes create a new pinned profile or release; retained failed attempts cannot be hidden or rewritten into successful grades.

## Attribution and publication

A sole PR author whose manifest allocates 100% of the outcome to their own numeric GitHub ID may acknowledge responsibility through the template's explicit rights and responsibility declarations. The broker checks the current head and records the body/artifact/terms binding. Other beneficiaries must acknowledge their own shares. Unacknowledged shares remain withheld.

Research merges require successful trusted admission and unprivileged CI checks at the current head and base. Only a signed, verified decision publication creates leaderboard credit. Family totals follow the cumulative high-water rule across PRs; support files, repeated experiments and administrative repairs do not create duplicate credit. Weekly/monthly/all-time standings use verified earning dates and respect profile visibility preferences.

## Founding governance

This is the operator-authorized bootstrap of the first scored release, before any competitive credit has been issued. Its governance PR is reviewed and checked by the trusted operator outside candidate code; it cannot award itself points. For this founding release, the operator's explicit launch instruction replaces the draft seven-day/two-human appointment requirement. Ongoing rubric changes must still be public, versioned and prospective. The public calibration study is not marked passed as a consequence of this exception.
