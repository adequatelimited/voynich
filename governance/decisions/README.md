# Authoritative decision ledger

Only verified broker-generated decision PRs add official event JSON here. Each event binds the actual accepted research merge, exact evidence, effective policy/profile, authenticated model/authority receipts, trusted merge-order predecessors and exact paid/held allocations. Contributors cannot authorize awards by writing JSON or naming themselves as reviewers.

Decisions are append-only; corrections preserve consumed high-water history and the original research earning period. Replaying requires current/historical delegated receipt verification. The repository contains no competitive award until such a decision is actually accepted. The initial seed snapshot builder refuses nonempty decision files rather than trusting them.
